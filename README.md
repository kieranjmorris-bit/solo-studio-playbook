# Solo Studio Playbook

Operating canon for solo design/architecture studios. Built by [Habitat Landscape Design](https://habitatlandscape.com.au) (Kieran Morris) because no canonical OSS exists for this specific shape: one-person creative practice, AU/NZ market, AI-augmented workflow.

## What's here

| Folder | Contents |
|---|---|
| `01-sales-pipeline` | Enquiry → fit-screen → discovery → workshop → proposal → invoice cadence |
| `02-discovery-call` | Pre-call brief, scorecard template, post-call follow-up |
| `03-proposal-templates` | Package descriptions, fee structures, scope delineation |
| `04-delivery-emails` | Concept / Masterplan / Planting / Completion email patterns |
| `05-weekly-cadence` | Monday standup, Thursday review, Friday planning rituals |
| `06-folder-structure` | Lead / Client / Archive folder schema (canonical naming) |

## Status

Skeleton scaffold 2026-05-19. Content to follow — current Habitat-internal versions will be sanitised (client names removed) and shipped here as the canon.

## Why this exists

Per agent research (subagent `a5f25924ce9068c41` 2026-05-19): there is no canonical OSS for solo design-studio sales-pipeline doctrine, despite extensive coverage of indie SaaS / dev-tool sales playbooks. Indie Hackers talks about it; nobody coded it. Tiago Forte / BASB is PKM-shaped, not ritual-shaped. GTD is proprietary.

This repo aims to fill that gap with executable opinionated process: not "consider doing X", but "do exactly X, here's the template, here's the script that generates the follow-up email".
